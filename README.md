# 4G Dongle Firmware Portal

A fast, searchable web directory and download portal for Qualcomm Snapdragon 410 (MSM8916) 4G USB modems and dongles (UZ801, UFI001B, Melbon, WhiteStick).

🌐 **Live Website**: [https://akbar-npj.github.io/4g-dongle-firmware/](https://akbar-npj.github.io/4g-dongle-firmware/)  
📦 **Release Archive**: [https://github.com/akbar-npj/4g-dongle-firmware/releases/tag/v1.0.0](https://github.com/akbar-npj/4g-dongle-firmware/releases/tag/v1.0.0)

---

## Overview
All 14 firmware packages (total ~2.5 GB) are hosted directly within this repository's releases:
- **Independent Storage**: These files are permanently preserved in this repository and are completely independent of upstream or temporary test tags.
- **Direct High-Speed Downloads**: Direct links to all firmware binaries hosted on GitHub Releases CDN.
- **Device-Specific Filtering**: Instantly filter images for UZ801, UFI001B, Melbon, WhiteStick, and generic Qualcomm baseband firmware.
- **SHA-256 Verification**: One-click copy for cryptographic image verification.
- **Step-by-Step Flashing Guide**: Complete EDL and Fastboot commands with one-click copy buttons.
- **Live Sync**: Integrates with the GitHub Releases API to track real-time download counts and asset updates.
